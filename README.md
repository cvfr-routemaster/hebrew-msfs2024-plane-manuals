<h1 dir="rtl" lang="he">ערכות מעבר למטוסים לטייסי סימולטור</h1>

<p dir="rtl" lang="he">מדריכי מעבר ובד״ח בעברית למטוסים ב־<span dir="ltr">MSFS 2024</span>, לטייסי סימולטור שמכירים את הססנה <span dir="ltr">172</span>.</p>

<p dir="ltr" lang="en">Hebrew aircraft starter kits for Microsoft Flight Simulator 2024 (MSFS 2024), with transition guides and checklists for pilots moving beyond the Cessna 172.</p>

<p dir="rtl"><strong><a href="https://cvfr-routemaster.github.io/hebrew-msfs2024-plane-manuals/"><span lang="he">אתר הפרויקט</span> · <span dir="ltr" lang="en">Project website</span></a></strong></p>

<div dir="rtl" lang="he">

## מה כוללת כל ערכה

כל ערכה מסבירה את מערכות המטוס ואת ההבדלים בהטסתו לעומת הססנה <span dir="ltr">172</span>, וכוללת טבלאות השוואה וביצועים, בד״ח לשלבי הטיסה הרגילים ונוהלי חירום נבחרים.

</div>

## What's in each kit

Each kit explains the aircraft's systems and handling differences from the Cessna 172, provides comparison and performance references, and covers normal flight phases and selected emergency procedures.

<div dir="rtl" lang="he">

## לשימוש בסימולטור בלבד

**המדריכים מיועדים לטיסה בסימולטור בלבד.** אין להסתמך עליהם להפעלת מטוס אמיתי, לתכנון טיסה אמיתית או להדרכת טיסה בפועל.

ייתכנו הבדלים מהותיים בין המודול בסימולטור לבין המטוס האמיתי, לרבות ברמת הדיוק של ההדמיה, בהתנהגות המערכות ובנוהלי ההפעלה. אין להחיל על מטוס אמיתי נוהל או תגובה המתוארים עבור הסימולטור.

</div>

## Simulator use only

**Intended for use in simulated flight only.** These guides make no claim or representation that they are suitable for use in real-life airplanes, real-world flight planning, or real-world flight instruction. Do not rely on them for those purposes.

Simulated aircraft may differ substantially from their real-world counterparts in fidelity, accuracy, systems behavior, and operational procedures. A procedure or aircraft response described for a simulator must not be assumed to apply to a real airplane.

<div dir="rtl" lang="he">

## המטוסים הזמינים

כל המדריכים מיועדים ל־<span dir="ltr">MSFS 2024</span>. השתמש במדריך המתאים לדגם המטוס ולמודול הסימולטור המצוינים בכותרתו. גרסת המודול והציוד האופציונלי עשויים להשפיע על החיוויים, הנהלים והביצועים.

</div>

## מבנה המאגר

לכל מטוס יש תיקייה משלו ובה מדריך ראשי בפורמט <span dir="ltr">Markdown</span> והתמונות המוטמעות בו. אפשר לקרוא את המדריך עם התמונות ישירות ב־<span dir="ltr">GitHub</span>. בהורדה או בשיתוף, שמור את קובץ המדריך ואת תיקיית <code dir="ltr">assets</code> יחד כדי שהתמונות יוצגו.

בעת פרסום ערכה חדשה, הוסף את המטוס לטבלה לפי הסדר האלפביתי של שם המטוס באנגלית. אתר הפרויקט מאוחסן בתיקיית <code dir="ltr">docs/</code> באמצעות <span dir="ltr">GitHub Pages</span>. הוסף גם כרטיס למטוס באתר, באותו סדר כמו בטבלה.

</div>

## Repository layout

Each aircraft has its own folder containing one main Markdown guide and its referenced images. Open a guide directly on GitHub to read it with its images. Keep the guide and its `assets` folder together when downloading or sharing them so inline images continue to work.

Add newly published aircraft to the table in alphabetical order by aircraft name. The `docs/` folder holds the project website (GitHub Pages). Each newly published aircraft also needs a card there, in the same order as the table.

```text
LICENSE
README.md
diamond-da42-vi/
  diamond-da42-vi-starter-kit.md
  assets/
    aircraft.jpeg
```
